# unemployment-analysis-reproducible
Reproducible unemployment analysis with Python
Unemployment Analysis with Python

Project Overview

This project analyzes unemployment trends across Indian states and regions using Python.

The project follows a reproducible research workflow. The research question, hypotheses, variables, exclusions, and analysis plan are documented before examining the outcome relationships.

Research Question

How did the unemployment rate change across Indian states and regions during the COVID-19 period, and how did it differ from the period before COVID-19?

Project Structure

- "raw/" — raw dataset
- "interim/" — intermediate data
- "processed/" — processed data
- "notebooks/" — analysis notebooks
- "report/" — analysis report
- "tests/" — synthetic pipeline tests
- "preregistration.md" — analysis preregistration
- "requirements.txt" — Python dependencies

Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

Reproducibility

The analysis plan is documented before outcome analysis. The repository includes the required project structure, environment dependencies, and a synthetic pipeline test to support reproducibility.
